To run the live draw

  1. Upload a CSV with numbers, real first names and preferred names, or use numbers only. Enter requests using student numbers.
  2. Save your setup, then click Open class screen.
  3. Keep this teacher tab open in the same browser. Project only the class screen.
  4. Click Draw presentation groups on the class screen, then reveal groups.
  5. Save the results as CSV. Use Clear tab data when you are finished.

This version works entirely on GitHub Pages. Draws are not synchronized to other computers. The class-screen link only connects to this browser.

How requests affect randomness and balance

The app uses the fewest groups needed, with at most 8 groups and 6 students per group, and first tries to balance their sizes. Sizes may vary to honor requests. With requests, randomized search finds a valid arrangement; it does not give every possible arrangement an equal probability. No rule is silently ignored.
